# Українська локалізація — The Guild 1 Remake: Europa 1410

Фанатський переклад гри на Unreal Engine 5.6. Мод підміняє англійські тексти українськими,
оригінальні файли гри не змінюються.

Переклад безкоштовний і таким лишиться. Якщо він припав до душі, можна кинути монету вдячності
в скарбничку писаря: **https://send.monobank.ua/jar/8ZddSdGUd7**

## Для гравців

Завантажте останній архів на сторінці [Releases](https://github.com/furmonenko/guild-europa1410-ukrainian/releases).

1. Відкрийте теку гри (Steam: правою кнопкою по грі → «Керувати» → «Переглянути локальні файли»).
2. Перейдіть до `Europa1410\Content\Paks` і створіть теку `~mods` (тильда на початку обов’язкова).
3. Розпакуйте в неї три файли: `ZZ_Ukrainian_P.pak`, `.utoc`, `.ucas`.
4. У налаштуваннях гри виберіть **English**: переклад підміняє саме англійську.

Видалити мод: прибрати ті самі три файли. Персонажі зі старих збережень лишаться з латинськими іменами
(гра дає ім’я при народженні), у новій партії імена будуть кирилицею.

Одруківки, кострубаті фрази, написи, що не влізли в кнопку: [Issues](https://github.com/furmonenko/guild-europa1410-ukrainian/issues),
бажано зі знімком екрана.

Решта цього файлу — для тих, хто хоче збирати мод самостійно або допомагати з перекладом.

## Швидкий старт

Потрібні Python 3.11+ і Windows (інструменти пакування — Windows-збірки).

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python uk.py tools      # завантажує repak і retoc (перевірка sha256)
python uk.py extract    # дістає оригінальні тексти з гри в work/
python uk.py install    # перевіряє, збирає й кладе мод у гру
```

Шлях до гри за замовчуванням: `D:\SteamLibrary\steamapps\common\The Guild - Europa 1410`.
Інший шлях: `--game "<шлях>"` або змінна середовища `EUROPA1410_DIR`.

У грі має бути вибрана **англійська** мова. Видалити мод: `python uk.py uninstall`.

## Команди

| Команда | Що робить |
|---|---|
| `tools` | завантажує repak/retoc у `tools/` |
| `extract` | витягує `.locres` з `Europa1410-Windows.pak` у `work/original/`, а тексти для перекладачів (en + de) — у `work/source/` |
| `check` | перевіряє переклади: плейсхолдери й теги на місці, ключі існують, англійський оригінал не змінився |
| `status` | покриття перекладу по розділах (`--all` — включно з неперекладеними) |
| `build` | `check` + збирання `dist/ZZ_Ukrainian_P.{pak,utoc,ucas}` |
| `package` | `build` + архів `dist/Europa1410-UA-<версія>.zip` із `ЧИТАЙ-МЕНЕ.txt` для розповсюдження |
| `install` / `uninstall` | `build` + копіювання в `Paks/~mods` / видалення звідти |

## Структура

```
uk.py                  CLI
ukloc/formats.py       читання .pak v11, читання/патч .locres v3
translations/<ціль>/<розділ>.json   переклади — єдине, що редагується вручну
glossary.md            глосарій термінів
termcodes.json         канонічні українські терміни для інлайн-кодів {XXX_C}…{##}
translate.py           LLM-драйвер: run / review / apply / terms / log (див. docs/plan.md)
docs/translator-brief.md  системна інструкція для перекладу (людьми чи LLM)
docs/prompt-*.md       завдання для чернетки й рецензії, докладаються до брифу
docs/release/          тексти для розповсюдження: readme в архіві, Nexus, kuli.com.ua, Steam, лист до видавця
work/                  (не в git) витягнуті з гри файли
tools/, dist/          (не в git) інструменти й зібраний мод
```

Формат перекладу — ключ із гри, англійський оригінал на момент перекладу і переклад:

```json
{
  "General_MainMenu_NewGame": { "en": "New Game", "uk": "Нова гра" }
}
```

Поле `en` потрібне, щоб після оновлення гри `check` показав рядки, у яких змінився оригінал.

## Як це працює

- Тексти гри лежать у `Europa1410-Windows.pak` (не зашифрований, стиснення Oodle) у файлах
  `Europa1410/Content/Localization/<ціль>/<мова>/<ціль>.locres`. Цілі: `Game` (основний текст),
  `Game_VO` (озвучені репліки), `Uncategorized Texts` (тексти, вшиті у віджети).
- Збирання бере оригінальний англійський `.locres`, дописує українські рядки в кінець таблиці рядків
  і перенаправляє на них перекладені ключі. Хеші не змінюються, тож гра вважає переклад актуальним.
  Неперекладені ключі лишаються англійськими.
- Результат пакується в `ZZ_Ukrainian_P.pak` (V11, без стиснення). Суфікс `_P` дає паку пріоритет над основним.
- UE5 пропускає `.pak`, поряд з яким немає IoStore-контейнера (у лозі гри:
  `IoStore container "...utoc" not found`), тому поруч кладеться порожня пара `.utoc/.ucas` від `retoc`.
- Шрифти гри кирилицю підтримують.

## Відомі обмеження

- **Множина.** Переклад займає місце англійської мови, тому форми рахуються за англійськими правилами:
  1 → `one`, все інше → `other`. Тобто «2 ходів» замість «2 ходи». У перекладах уже є форми `few`/`many`,
  вони запрацюють, коли з'явиться окрема мова `uk`.
- **Оновлення гри.** Після оновлення треба заново зробити `extract` і `check`. Мод побудовано з англійського
  `.locres` конкретної версії, тож старий мод на новій версії гри може показати застарілі англійські тексти.
