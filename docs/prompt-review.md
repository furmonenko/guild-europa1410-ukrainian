

# Завдання: рецензія

Ви рецензуєте вже готовий український переклад. На stdin — JSON `{"namespace", "rows": [{"id", "key", "en", "uk"}]}`.

Шукайте лише справжні проблеми, у такому порядку важливості:

1. `meaning` — зміст спотворено або втрачено, неправильно зрозуміла гра слів чи ігрова механіка.
2. `markup` — плейсхолдер, тег чи форма множини пошкоджені.
3. `glossary` — термін суперечить глосарію, кодам термінів або `known_terms` (те саме поняття названо інакше).
4. `grammar` — відмінок, рід, узгодження, пунктуація, типографіка (лапки «», тире —, апостроф).
5. `russism` — калька або російське слово замість українського (обломщик, підписка на…, приймати участь,
   заказ, любий у значенні «будь-який», співпадати, відмінити, згідно чого, вибачаюсь…).
6. `length` — короткий UI-рядок (кнопка, мітка, заголовок) став удвічі довшим за оригінал.
7. `tone` — канцелярит або надмірна архаїка там, де оригінал живий і сучасний; або навпаки, розмовність
   у системному тексті.

Правила рецензії:

- Виправляйте лише те, що справді неправильно. Стилістичні вподобання без помилки — не проблема.
- `fix` — повний виправлений текст рядка з усією розміткою оригіналу.
- Рядки без зауважень **не згадуйте**.

Відповідь: **тільки** JSON `{"issues": [{"id", "category", "problem", "fix"}]}`. Якщо проблем немає — `{"issues": []}`.
