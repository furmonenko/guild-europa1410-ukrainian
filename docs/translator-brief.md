# Бриф для перекладу нового розділу

Цим брифом перекладались перші розділи (агентами Sonnet, паралельно, по одному розділу на агента).
Для нового розділу, наприклад `Game/Items`:

1. `python uk.py extract` — у `work/source/Game/Items.json` з'являться рядки `{key, en, de}`.
2. Дати перекладачеві цей файл, `glossary.md` і правила нижче.
3. Результат зберегти в `translations/Game/Items.json` у форматі `{key: {"en": ..., "uk": ...}}`.
4. `python uk.py check`, виправити помилки, `python uk.py install`, перевірити в грі.
5. Нові терміни внести в `glossary.md`.

## Правила

- Гра: стратегія про династії й економіку, Центральна Європа (Богемія), 1410 рік. Серія The Guild.
- `de` — офіційний німецький переклад, лише як підказка до змісту.
- Дотримуватись `glossary.md`.
- Розмітку зберігати побайтово, міняти можна лише її позицію в реченні:
  - `{Value}`, `{NumTurns}`, `{icon}`, `{0}` — плейсхолдери;
  - `{C_TRN_C}`…`{##}` — кольорові/інтерактивні терміни, перекладається лише текст між ними;
  - `<text fontface="bold">`…`</>` — rich-text теги;
  - `\n`, `\r\n`; `[Space]`, `[Esc]`, `[surname]` — лишаються як є.
- Множина: `{N}|plural(one=…,few=…,many=…,other=…)` — усі чотири українські форми, без `,` і `)` усередині.
- Звертання до гравця у описах — «Ви/Ваш» з великої; кнопки — коротко, інфінітив або наказовий спосіб.
- Кнопки й мітки — близько до довжини оригіналу (місця в інтерфейсі мало).
- Чеські імена й прізвища — без змін латиницею. Технічні ідентифікатори (`StoneSoil`, `COLOR`) — без змін.
  Реальні міста — українською (Нюрнберг). Назви будівель і жартівливі назви — творчо, зі збереженням тону.
- Типографіка: «лапки», тире —, три крапки …, апостроф ’ або '.
