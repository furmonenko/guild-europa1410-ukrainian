# Бриф для перекладу The Guild 1 Remake: Europa 1410 українською

Цей файл — системна інструкція для перекладача (людини чи LLM). Він іде разом із `glossary.md`
і `termcodes.json` у кожен виклик драйвера `translate.py`; далі — конкретне завдання.

## Гра

Стратегія про династії, ремесло, торгівлю, інтриги й політику. Центральна Європа (Богемія),
1410 рік. Серія The Guild. Гравець керує родиною: будує майстерні, купує будівлі, обіймає посади,
судиться, шкодить суперникам. Хід — це ігровий раунд (`turn`), сезон — 4 ходи.

## Тон

- Інтерфейс — сучасна, чиста, лаконічна українська. Не архаїка, не канцелярит.
- Описи, події, репліки — жива мова з легким середньовічним колоритом. Оригінал часто іронічний
  або з грою слів; передавайте дотепність, а не дослівність.
- Звертання до гравця у описах і подіях — «Ви/Ваш» з великої літери. Кнопки й дії — коротко,
  інфінітив або наказовий спосіб («Побудувати», «Найняти», «Скасувати»).
- Жодних русизмів і кальок: не «обломщик», «приймати участь», «заказ», «любий» (у сенсі «будь-який»),
  «співпадати», «відмінити», «згідно чого», «вибачаюсь», «на протязі». Сумніваєтесь — беріть
  питоме українське слово.

## Розмітка (зберігати побайтово, міняти можна лише позицію в реченні)

- `{Value}`, `{NumTurns}`, `{charactername}`, `{0}` — плейсхолдери, підставляються грою.
- `{CHAR_STA_C}текст{##}` — кольоровий інлайн-термін: код лишається, перекладається лише текст
  між `{…_C}` і `{##}`. Канонічні українські терміни для кодів — у `termcodes.json`; відмінюйте
  за контекстом, але корінь має лишатися впізнаваним і однаковим по всій грі.
- `<text fontface="bold">…</>` — rich-text теги.
- `\n`, `\r\n` — переноси; `[Space]`, `[Esc]`, `[surname]` — лишаються як є.
- Множина: `{N}|plural(one=…,few=…,many=…,other=…)` — усі чотири українські форми
  (one=1 хід, few=2–4 ходи, many=5+ ходів, other=дробові), без `,` і `)` усередині форм.
- `{Gender}|gender(…)` — форми для чоловічого/жіночого роду в тому ж порядку, що в оригіналі.

## Імена й назви

- **Імена та прізвища — транслітерувати кирилицею** за практичною транслітерацією, без відмінювання
  чужомовних форм там, де це виглядає штучно.
  Чеська: h → г, ch → х, c → ц, č → ч, š → ш, ž → ж, ř → рж (після глухих — рш), ď/ť/ň → дь/ть/нь,
  ě → є, j → й (ja/je/ji/ju → я/є/ї/ю), y/ý → и, i/í → і, ů/ú → у, g → ґ; довгота не позначається.
  Приклади: Jan Hus → Ян Гус, Jiří → Їржі, Dvořák → Дворжак, Václav → Вацлав, Novák → Новак,
  Kutná Hora → Кутна Гора, Karel → Карел, Anežka → Анежка, Vojtěch → Войтех.
  Німецька: Heinrich → Гайнріх, Nürnberg → Нюрнберг, Schwarz → Шварц, ei → ай, eu → ой, h → г.
- Реальні міста — усталеними українськими назвами (Прага, Нюрнберг, Відень, Краків).
- Назви будівель, гільдій, возів з `Name Pools` та «ambient backstories» — це жарти й каламбури.
  Адаптуйте українськими жартами зі збереженням тону (не дослівно). Такі рядки затверджуються
  окремо, тому дотепність тут важливіша за буквальність.
- Технічні ідентифікатори (`StoneSoil`, `COLOR`), `TBD`, `(LocMe)…`, римські цифри, бренди
  (Steam, Discord) — без змін.

## Мова

- Дотримуйтесь `glossary.md` і `termcodes.json`; одне поняття — одне слово по всій грі.
- Кнопки й мітки — близько до довжини оригіналу (місця в інтерфейсі мало).
- Типографіка: «лапки», тире —, три крапки …, апостроф ’ або '.
- Числівники і одиниці — як в оригіналі; валюта — «монети/гроші» за глосарієм.

## Робочий процес (для людини)

1. `python uk.py extract` — тексти гри у `work/source/<ціль>/<розділ>.json` (`{key, en, de}`).
2. `python translate.py run Game/Items --model sonnet --max-cost 1` — чернетка з валідацією.
3. `python translate.py review Game/Items --model opus` → `work/review/Game/Items.json`;
   переглянути, зайве видалити, `python translate.py apply Game/Items`.
4. `python uk.py check`, `python uk.py install`, перевірити в грі.
5. Нові терміни — у `glossary.md`; зауваження з гри — сюди або в глосарій; закомітити.
