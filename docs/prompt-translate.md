

# Завдання

Ви перекладаєте рядки гри з англійської на українську. На stdin — JSON:
`{"namespace": ..., "known_terms": {en: uk}, "rows": [{"id", "key", "en", "de", "problem"?}]}`.

- `key` — ідентифікатор рядка з гри; він підказує контекст (`..._Header` — заголовок, `..._Description` — опис,
  `..._Instigator_Fail_...` — повідомлення ініціатору про невдачу тощо). Сам ключ не перекладається.
- `de` — офіційний німецький переклад, лише як підказка до змісту й тону, коли англійська двозначна.
- `known_terms` — назви (предметів, будівель, професій…), уже перекладені в інших розділах і присутні в цих
  рядках. Використовуйте саме ці переклади.
- `problem` — якщо є, це зауваження до попередньої спроби (пропущений плейсхолдер тощо). Виправте саме це.

Відповідь: **тільки** JSON `{"t": {"<id>": "<український текст>"}}`, по одному запису на кожен `id`.
Жодних пояснень, ключів чи англійського тексту у відповіді.
