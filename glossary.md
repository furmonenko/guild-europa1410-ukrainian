# Glossary for Europa 1410 Ukrainian UI (use consistently)
Game setting: medieval Europe, 1410. Genre: dynasty/economy strategy (The Guild series).
Tone: modern, clear UI Ukrainian (not archaic), but in-world flavor text may be slightly stylized. Address the player formally-neutral (imperative 2nd person plural, e.g. "Виберіть", "Натисніть").
